# habit-tracker-ios

Personal habit tracker for **iPhone** — SwiftUI, local-first MVP.

## Status

🚧 Early development (Xcode + Cursor)

## Scope (MVP)

- Custom habits (name, optional schedule)
- One tap check-in per day
- Simple streak / history view
- iPhone only

## Stack

- Swift 5, SwiftUI
- SwiftData (or UserDefaults for v0)
- Xcode, iOS Simulator

## Getting started

1. Clone the repo
2. Open `HabitTracker.xcodeproj` in Xcode
3. Select an iPhone simulator → **Run** (⌘R)
